# Acronym Flashcards

A simple command-line flashcard application in Python to help learn acronyms, their full forms, and descriptions.

## Features
- Loads data from a CSV file
- Two study modes: sequential review and random quiz mode
    - Allows Esc to get back to the main menu
- Clean flashcard-style interface with Enter to reveal answers
- Acronym lookup mode when you just want to know it's meaning

## How to Run

```bash
py study_flashcards.py
